## ربات فاکسیما — نسخه ریفکتور شده از ربات میرزا

> این مخزن یک **فورک** از [Mmd-Amir/Faoxima](https://github.com/Mmd-Amir/Faoxima) است که قابلیت **کانفیگ رایگان برای زیرمجموعه‌گیری** به آن اضافه شده است. نصب و آپدیت از همین فورک انجام می‌شود.

ربات فاکسیما یک بازطراحی کامل و بهینه‌سازی شده از ربات میرزا است که با هدف ارتقای تجربه کاربری و افزایش کارایی طراحی شده است.

---

### 🎁 کانفیگ رایگان با زیرمجموعه‌گیری (ویژه این فورک)

کاربر با لینک اختصاصی خودش (`https://t.me/<bot>?start=<user_id>`) دوستانش را دعوت می‌کند و بعد از رسیدن به تعداد تعیین‌شده توسط ادمین، یک کانفیگ رایگان می‌گیرد.

**سمت کاربر** — منوی «زیرمجموعه‌گیری»:
- نمایش تعداد زیرمجموعه لازم و پیشرفت (`X از Y نفر`)
- نمایش تعداد کانفیگ دریافت‌شده از سقف مجاز
- دکمه «🎁 دریافت کانفیگ رایگان» فقط وقتی جایزه قابل دریافت باشد

**سمت ادمین** — پنل مدیریت → زیرمجموعه‌گیری:
- «🎁 کانفیگ رایگان زیرمجموعه» : روشن/خاموش کردن قابلیت
- «👥 تعداد زیرمجموعه لازم» : تعداد دعوت لازم برای هر کانفیگ
- «🎟 سقف کانفیگ رایگان» : حداکثر تعداد کانفیگ رایگان هر کاربر

**نحوه ساخت کانفیگ:** از همان مسیر سرویس تست ربات (پنلی که `ONTestAccount` دارد) با حجم `val_usertest` و زمان `time_usertest`؛ سرویس در جدول `invoice` ثبت می‌شود و در «سرویس‌های من»، گزارش‌ها و کانال گزارش هم دیده می‌شود.

**دیتابیس:** ستون‌های `freeconfig_status` / `freeconfig_count` / `freeconfig_max` روی جدول `affiliates` و جدول `affiliate_freeconfig` (کلید یکتای `id_user + reward_index`). این ساختار موقع اجرای `table.php` روی نصب‌های قبلی هم به‌صورت خودکار ساخته می‌شود.

**ضدتکرار:** هر جایزه با ایندکس مشخص رزرو می‌شود؛ درخواست تکراری/همزمان رد می‌شود و اگر ساخت کانفیگ روی پنل شکست بخورد، رزرو حذف و فاکتور `Unsuccessful` می‌شود تا کاربر جایزه‌اش را از دست ندهد.
